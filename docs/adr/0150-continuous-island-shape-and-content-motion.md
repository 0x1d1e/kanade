# 150. Continuous Island shape and content motion

Status: accepted. Amends ADRs 0030, 0101 and 0145.

## Context

A single circular clip did not agree with the shell shader's changing corner exponent. Prepared shadow images switched between resting radii and orientations, depended on image readiness, and could disappear below the smallest prepared radius during undershoot. Fixed horizontal Compact width also left short content spread across a long body. Usage had source data and policy but no specialized forms.

## Decision

- Shell rectangles explicitly opt into `Rectangle::continuous`; the default for controls and Arc stays circular. Each corner uses smoothing 0.72 clamped independently to the room on each edge, with cubic shoulders and a cubic approximation of the intervening circular arc. The construction adapts islandcn's MIT path algorithm, credited in `THIRD_PARTY_NOTICES.md`.
- `Area::trace`, quad fill/border and both clip layers use the same profile. The vector border fills the outer path minus the full-thickness inset, matching the quad route under transforms. A continuous outer shell clip survives deeper clip nesting. Pane, merged Dock and Satellite body shaders include the same WGSL distance function. Dots stay circular; Satellite necks remain excluded from compositor blur. Blur spans use the same precomputed corner and inspect curved edge pixels, skipping only a known solid rectangular core.
- Shell shadows use a clock-free signed-distance Gaussian edge approximation over the actual current body and radius. The current outline punches out its interior. This removes radius-bank swaps, clamped texture stretching, readiness-driven replacement and small-radius disappearance. The ambient/contact colors, spreads, drop and sixteen target slots remain. There is no per-frame raster generation, image decode, or shadow preparation thread.
- Opening keeps configured damping. Closing derives `1 - (1 - damping) * (0.06 / 0.28)`, giving 0.94 at the default 0.72. A downward Presentation change has a shallow long-axis waist then a settle prepared analytically at its exact deadline. Body owns that pending leg; service deadlines advance it, including offline inspection. Final target queries always mean the final body. Interruption samples the active leg and cancels the pending one while preserving position and velocity. The content phase starts once. Reduced motion and zero-duration changes bypass the waist.
- Horizontal Compact asks are measured as bounded integer widths outside view builds, using existing typography plus the actual icon, value, visualizer and control lanes and privacy reservation. Width is at most 220 px. Countdown and progress digit lanes reserve their space independently of the current digits. The service stores active asks per Activity and freezes one outgoing extent per island with its departing Content, so a new generation sharing an Id cannot resize the old form while visible. Its finite departure deadline clears that snapshot. Split uses that same Compact extent plus its existing trailing segment. Layout, hit segmentation and geometry resolve the same extent, with the canvas fixed and old input bounds held while shrinking. Upright forms retain their existing vertical organization; countdown parts use 15 px, and Live uses 15 px digits over a separate percent unit so 100% fits the narrow body.
- Small forms follow the current body within scale 0.94–1.02 and translation of at most 3 px. Existing runtime transforms carry their hit targets. Expanded Surface layouts stay fixed, and Reduced motion bypasses this follow. The existing outgoing/incoming half-opacity gate, permanent cancellation across ineligible frames, keyboard ownership and privacy placement remain authoritative.
- Passive Volume/Brightness/Keyboard and Live progress fills use service-owned springs keyed by Activity identity and Live start serial. Sampling is read-only; views request frames only for a visible moving fill. Raw source numbers remain unchanged. Changed targets retain velocity, displayed fractions stay bounded, and settled endpoints are exact. Withdrawal, missing progress or a new serial retains only an outgoing displayed generation until its finite departure deadline; a hidden old generation is discarded. Directly manipulated Surface sliders and Media timelines retain their own input behavior.
- Compact titled labels use SemiBold. Live/timer short values use 15 px with room for three digits or a short countdown; Peek numbers and pad headers use the existing 17 px token, and pad tile/pill labels the 13 px label token. Active Recording Satellites use the 14 px Capture icon; paused recordings keep Pause and capture color.
- Usage Compact/Peek show both optional real fractions as labeled five-hour/seven-day rings; Split reuses Compact and Satellites use concentric rings. A missing window says `N/A`, distinct from a known 0%. Notice forms show their actual message. These views read Activity data only and add no Surface, credential path or network request.

## Consequences

Motion retains one content handoff and a finite service deadline for a pending close settle. Nothing in the new shaders reads time. Shared shell corners require deliberate opt-in; a control does not change shape merely because it uses Rectangle. Shadow softness is now a distance-based Gaussian approximation instead of a preblurred bitmap. New lifecycle checks cover interruption around the handoff, replay sampling, reduced motion and progress identity/cleanup; visual checks use the real renderer with synthetic Usage/Recording fixtures.
