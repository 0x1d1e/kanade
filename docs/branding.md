# Kanade Branding

The Kanade mascot and visual identity are original artwork created for
the Kanade project. The mascot is Kanade's own original character and
has no name.

They are not affiliated with or endorsed by any anime, game, character,
studio, publisher, or other third-party franchise.

Third-party use of the Kanade name and branding does not imply
endorsement by the Kanade project.
